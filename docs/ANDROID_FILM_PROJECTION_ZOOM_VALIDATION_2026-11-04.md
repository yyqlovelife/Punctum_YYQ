# 胶片投影区缩放 · 2026-11-04

## 结果与边界

胶片投影区已接入普通大图页相同的1–5倍保留缩放模型：双指缩放、松手保留、单指平移、连续缩放锚点、手指加入/离开跳过质心突变、放大时双击弹簧还原、双指缩回1倍。照片只在投影区内部显示，超出幕布的部分由整个投影区裁切；不会盖住下方标题和选片台。放大期间暂停投影左右快切/分页及上滑删除，复原后恢复。

用户明确当前未插手机。本轮无真机安装或手感验收；只在本机Android API36模拟器（1080×2400、density2.625）验证实际手势。模拟器装同源Debug构建，签名Release另行构建/验证。未同步GitHub；用户随后授权上传谷歌，交付验证见文末。版本继续0.7.0/90。

## 实现

- `ProjectionPhotoZoom.kt`管理投影照片的保留姿态、手势所有权与还原动画；继续复用`PhotoZoomState`及原大图的5倍上限、.88/700弹簧参数。
- 缩放输入位于投影父容器的Initial阶段，双指优先接管，放大后单指拖动由照片持有；不会同时触发分页或删除。跨照片选择、信息状态切换、禁用交互、切后台、离开页面时清理缩放。
- `FilmReviewScreen.kt`仅对照片应用缩放层，手势几何使用照片真实适配尺寸与信息抬升位置，补偿抬升后的缩放中心。幕布光晕、文字与选片台不跟随放大。最外层`clipToBounds`固定裁切整个投影区。
- 实时姿态读取位于`graphicsLayer`，不逐帧重组照片/模糊光晕。此前上滑性能、光影交接修复保留。普通大图页本轮未改。
