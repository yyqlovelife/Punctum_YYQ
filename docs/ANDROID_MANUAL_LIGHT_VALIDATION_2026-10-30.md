# Android 手动开灯 · 2026-10-30 · 0.6.0/73

## 当前方案

每次进入图集保持熄灯，无自动开灯。标题右侧是 34×18dp 骨白与炭灰的横向机械拨动开关，保留 48×48dp 可访问触控区与 Role.Switch / 开关状态描述。开关去掉系统 Ripple，按压本体外不显示方形热区。手动开灯直接从参考 900ms 帧开始，继续 3200ms；再次关灯取消原协程并复原暗态。每次离开再进入重置熄灯。系统关闭动画时仍保持初始熄灯，点击后直接终态。

更多按钮顶部从“状态栏安全区 + 8dp”上移至 4dp，右侧继续留 20dp，44dp 触控区域。原生 DropdownMenu 及每个项目的字体、配色、圆角、图标、回调原样保留。投影最小垂直留白从 24dp 改为 48dp，为顶部控件留出空间，竖向图会小幅收缩以避让；横图仍受原 24dp 左右边距限制。新测试覆盖竖图避让。

灯板与照片分别控制。灯板过曝峰值 253/253/253，参考时间 1.10–3.50s 使用 smoothstep 单向回落至 232/232/230；移除之前近乎全亮的 248/247/243 终态。照片继续采用统一颜色通道的原有细节恢复和原色终态，不加黄色色偏。网页和原生的灯板公式一致。
