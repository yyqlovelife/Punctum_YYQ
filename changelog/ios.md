# iOS 更新说明

## 0.5.8 · 2026-09-16

仅 iOS，版本保持 `0.5.8 / 58`。汇总 9 月 15–16 日的能力对齐、浏览修复和删除动效重做。用户已在真机确认原生快照版删除明显更流畅，并确认最终 **280ms** 收缩节奏可以保留。

### 大图与删除

- 照片区域支持 1–3 倍双指临时放大，放大时双指上下左右移动可平移照片；松手后大小和位置一起回弹，黑色参数区保持原位。
- 上滑删除参照 Android 重做：卡片跟手抬起，超过范围后增加阻力，松手后用 280ms 收缩到删除图标。取消回弹约 300ms，减少动态效果模式使用 160ms 淡出。
- 拖动只移动当前页面的一张不可交互快照，卡片不能左右翻页；照片加载、EXIF 和分页树不参与逐帧更新。完成动画后再接替下一张，避免固定延时造成衔接跳变。
- 保留旧 SwiftUI 删除实现，通过 `nativeDeletionEnabled` 回退。历史 200ms / 400ms 飞出和早期跟手优化均不代表当前默认效果。
- 删除仍只加入当前浏览会话的待删除队列，退出大图统一确认；取消保留照片及图集列表，系统删除成功后才移除列表项。
- 高清图片请求合并，ImageIO 解码移至串行后台队列；参数预读限定当前及前后照片，停稳 180ms 后准备实况与参数。
- EXIF 优先从原始文件 URL 读取，减少大原图整体载入内存；每张读取完成即更新。预读按照片身份触发，修复连续删除后页码不变时停止预读的问题。云端原图仍可能等待读取。
- 每张照片保持固定分页视图和稳定身份，撤回导致左右翻页回弹的动态占位方案。
- 竖图顶部间距为零，超长竖图等比适配可用高度，横图位置保持原样；不恢复负顶部偏移或额外安全区留白。

### 首页与图集管理

- 对齐首页三种样式的卡片过渡、顶部标签、28 条名言和文字间距；按钮松手立即响应，保留减少动态效果适配。
- 邀请卡按压在窗口坐标下移动超过 10pt 后取消本次点击，滚动及减速期间拦截误触进入图集。
- 图集管理支持原生长按排序、触觉、边缘自动滚动和顺序持久化；保留旧箭头排序组件。面板优先滚动列表，列表占满可用高度。
- 添加图集锁定已经加入的项；关闭排序面板后再打开添加面板，避免两个 Sheet 竞争。三类 Sheet 统一暖深灰、圆角和描边。
- 缩略图按屏幕请求 360–900px，按 80 张分页；本地 EXIF 拍摄时间索引持久缓存，一次图集浏览固定排序快照。
- 进入图集先显示首批内容，不再等待整库索引或高清原图，修复大图集一直显示“正在准备图集”。
- 返回前台时仅在照片权限变化后补刷新，系统照片变更仍由监听处理；复用同一数据代的索引，批量准备定期让出主线程。
- 失活时清理按压、实况和缩放等中断状态，恢复暂停的翻页识别，取消尚未提交的删除拖动。

### 验证与交付

- iOS Release 构建通过；最近一轮 21 项自动测试全部通过，覆盖模型、日期、解码、照片布局、点击移动判定及删除轨迹。最终 400ms → 280ms 仅调时长，重新构建 Release 后由用户真机确认。
- 真机确认范围：原生删除流畅度及 280ms 节奏。邀请卡、后台恢复、长列表及各组合手势的完整验收仍按各自记录判断，不扩写为全部场景通过。
- 最新本地包：`iOS/IPA/Punctum-0.5.8-native-delete-280ms-unsigned.ipa`，使用原 AltStore 身份覆盖安装；安装包不纳入 Git。
- 当前交接见 [`PUNCTUM_HANDOFF.md`](../PUNCTUM_HANDOFF.md)，完整过程和证据见 [`design-qa.md`](../design-qa.md)。修改时间排序切换已回退，不在本版中。

以下版本章节保留历史迭代，当前状态以本节为准。

## 0.5.7 · 2026-09-15（待真机复测）

仅 iOS。以 Android 0.5.7 当前源码为参照，补齐图集管理、删除确认期间的列表稳定性、首页视觉与浏览过渡。版本和构建号更新为 `0.5.7 / 57`。Android 源码保持不变；本次不包含已经回退的“按文件修改时间排序”切换功能。

### 真机反馈修复：图集准备停滞

- 移除进入图集时对整本 EXIF 索引和首两张高清预览的等待。现在先打开首批照片，图片自行异步加载；后台时间索引不阻断导航。
- 图集本次浏览固定排序快照，进出大图与后续分页继续使用同一顺序；返回首页后再次进入时采用已完成的新索引。
- 修复包保持 `0.5.7 / 57`，使用独立文件名 `Punctum-0.5.7-gallery-entry-fix-unsigned.ipa` 避免误装上一包。下文原“等待准备后揭示”的描述已由本修复替代。

### 真机反馈修复：上滑删除卡片仍可翻页

- 上滑开始时固定当前照片、序号和已准备的参数，删除动效只作用于这张独立卡片；卡片关闭横向切页、实况播放和滚动交互。
- 原分页层在上滑与收尾期间隐藏并锁定选择；取消后回到原照片，确认后按固定照片身份加入待删除列表。保留 200ms 飞出与原回弹参数。
- 修复包保持 `0.5.7 / 57`：`Punctum-0.5.7-delete-card-fix-unsigned.ipa`，同时包含前述图集准备停滞修复；具体触感仍待真机复测。

### 真机反馈优化：上滑删除卡顿感

- 单张删除卡片提前挂载，避免开始上滑时临时创建照片页；卡片、接替照片与分页容器分别隔离更新，拖动进度变化时复用内容。
- 去掉大面积动态模糊阴影和轻微旋转，保留缩放、上移、200ms 确认飞出和取消回弹。减少动态效果时禁用缩放和自动回弹，并减小跟手位移。
- 保持单张卡片不可翻页、固定删除身份及原来的删除确认流程。新包为 `Punctum-0.5.7-swipe-performance-unsigned.ipa`，帧率改善仍待真机确认。

### 大图照片双指临时放大

- 两指均从照片区域开始时，可围绕起始捏合中心放大照片图层，范围 1–3 倍；松手后以短弹簧回到原尺寸。黑色详情区与文字不缩放、不重新排版。
- 缩放期间锁定翻页与上滑删除，停止当前实况播放；结束或取消手势时恢复滚动识别，回弹完成后解除操作锁。支持回弹途中再次捏合。
- 减少动态效果时使用 160ms 无弹跳复原。新包保持 `0.5.7 / 57`：`Punctum-0.5.7-photo-pinch-unsigned.ipa`，双指手感与真机手势冲突待复测。

### 真机反馈优化：大图左右翻页卡顿

- 高清图片请求按照片和目标尺寸合并，分页页与隐藏卡片共用一次加载和解码；解码明确移到串行后台队列。取消最后一个订阅者时取消 Photos 请求，过期结果不会写入新页面。
- 完整大图视图限制为当前页及前后各一页，其他页保留稳定身份与轻量占位；不再为未选中页加载实况资源。
- 快速切页时延后 180ms 再准备参数和实况。参数预读缩到当前页及前后各一张，结果合并发布；照片显示和手势本身不等待。
- 保留完整照片比例、EXIF 方向、捏合放大和单卡片上滑删除。新包保持 `0.5.7 / 57`：`Punctum-0.5.7-paging-performance-unsigned.ipa`，实际掉帧改善仍待真机复测。

### 紧急回退：左右翻页回弹

- 用户反馈上一包左右拖动无法完成翻页。撤回分页页随当前索引切换为占位视图的改动，恢复优化前每张照片直接对应固定分页子视图的结构，避免滑动中改变分页内容结构。
- 保留独立的图片请求合并、后台解码和参数/实况延迟准备；捏合与上滑删除保持原实现。
- 上述“三页完整视图”方案已撤回。替代包为 `Punctum-0.5.7-paging-rebound-fix-unsigned.ipa`，版本保持 `0.5.7 / 57`。

### 修复：竖图顶部显示不全

- 移除大图内容整体的负顶部间距，竖图从顶部安全区下方开始，避免顶端被移出屏幕或受顶部遮挡。
- 超长竖图按可用高度等比适配，完整显示上下边缘；照片比例不变，详情仍在照片下方。横图保持原来的视觉位置。
- 普通浏览、捏合放大与删除卡片使用同一照片布局。修复包为 `Punctum-0.5.7-portrait-fit-unsigned.ipa`，保持 `0.5.7 / 57`。

### 修正：竖图顶部贴屏显示

- 根据真机反馈，撤回竖图新增的顶部安全区留白。竖图从屏幕顶端开始，顶部间距为零，同时不恢复导致内容上移的负间距。
- 保留超长竖图等比适配、横图位置、捏合及删除能力。替代包为 `Punctum-0.5.7-portrait-edge-unsigned.ipa`，保持 `0.5.7 / 57`。

### 图集管理与删除

- 图集顺序管理新增原生交互式拖动：长按整行、1:1 跟手、换位触觉反馈、系统边缘自动滚动和原生落座；保留原箭头排序组件用于比较。
- 排序期间固定列表快照；结束后按图集稳定 ID 保存顺序，吸收等待中的数据刷新。无障碍提供上下移动和移除图集操作。
- 排序列表独立滚动，标题、完成和添加入口保持固定；继续使用 iOS 原生 Sheet。
- 退出大图后的待删除确认不再提前移除列表照片；取消保持列表原状，系统删除成功后统一移除。确认期间阻止后台刷新替换列表。
- 排序面板关闭完成后再打开添加面板，避免同时竞争 Sheet 展示。已添加图集文案统一为「已添加」，确认时再次排除已添加项。

### 首页与动效

- 顶部标签更新为 `- PUNCTUM · STUDIUM -`，顶部共同留白增加 6pt；首页名言由 17 条同步到 Android 的 28 条。
- 明信片数量/日期、票尾英文行距增加 2pt；票据数量和日期文字调整为 7pt。
- 按钮松手立即触发动作，取消原来的额外 240ms 导航等待；回弹独立进行。
- 样式切换只变换卡片区域，采用 120ms 退出、220ms 入场；快速重复切换会取消旧任务，避免停在透明状态。
- 首页等待图集排序索引与首行预览准备后揭示内容，进入约 180ms、返回约 160ms；首页常驻以保留滚动位置。
- 大图入场 180ms 淡入、退出 140ms 淡出；退出动画结束后才移除内容，过渡期间阻止底层列表响应。
- 上滑删除确认飞出缩短至 200ms，触发距离约 101pt，并加极淡描边；保留原分页锁定、替代照片冻结与实况播放机制。
- 系统减少动态效果时，首页切换移除位移与缩放，按钮使用透明度反馈；大图保持淡入淡出。

### 图片与拍摄时间

- 缩略图按屏幕实际显示像素提升清晰度，长边范围 360–900px；继续按 80 张分页及使用有容量限制的缓存。
- 新增可持久缓存的拍摄时间索引：本机原图 EXIF DateTimeOriginal（支持时区偏移）→ Photos creationDate → modificationDate；用于图集顺序、封面和时间跨度。
- 缓存按照片修改时间失效。iCloud 原图尚未在本机可用时，暂用系统时间，不为排序强制下载整库；首次本地索引可能需要等待，页面显示准备提示。
- 大图会话固定分页使用的图集顺序，防止系统相册更新或索引刷新在浏览中途改序。

### 验证与交付

- 编译、测试与设备检查的实际证据见根目录 `design-qa.md` 本轮记录。
- 模拟器已检查首页、排序面板、排序后关闭重开、图集进入、大图显示及边缘切图；长按跨页、Live Photo 声画和长时间滚动仍待真机复测。
- 本地 IPA 为 `iOS/IPA/Punctum-0.5.7-unsigned.ipa`，安装需沿用用户现有 AltStore 签名流程。不能将未签名包或模拟器检查等同于真机安装验收。

## 0.5.5 · 2026-08-31

本版完成大图页真机体验的最后一轮稳定性与性能优化，版本升至 `0.5.5`（build `55`）。未签名安装包构建后输出为 `iOS/IPA/Punctum-0.5.5-unsigned.ipa`，可交给 AltStore / AltServer 完成个人签名与侧载，安装包继续不纳入 Git。

### 参数信息无感衔接

- 画廊对当前可见照片提前读取参数；点击照片时把完整首屏数据直接交给大图页，消除参数区先黑后出现的变化。

- 删除一张照片后，背后的下一张会连同拍摄参数一起立即出现，不再发生参数文字二次加载或跳变。
- 拆分 EXIF 与地理位置解析，并合并同一照片的重复请求，减少无效读取和切图时的等待。

### 进入与切图性能

- 大图复用画廊已经生成的缩略图缓存，进入时先显示现有清晰内容，再平滑替换为高质量图像。

- 左右切换大图、上滑删除后承接下一张，都会预先准备图像与参数，三个入口的首帧表现保持一致。
- 画廊左上角返回按钮扩大可点击范围，保留既有的按下、回弹、再返回动效。

### 实况照片真机修复

- 修复实况照片触发震动后仍没有画面和声音的问题；实况资源到达后会继续完成待执行的播放请求。
- 长按照片和点击实况角标均可正常开播，画面、声音与松手停止逻辑已在 iPhone 14 Pro 真机验收通过。
- 保留实况播放期间的页面手势协调，避免播放层干扰单击沉浸态、左右切图和上滑删除。

### 真机验收

本版集中收录大图页真机交互修复与全局按压反馈，版本升至 `0.5.4`（build `54`）。本地未签名安装包输出为 `iOS/IPA/Punctum-0.5.4-unsigned.ipa`，可交给 AltStore / AltServer 完成个人签名与侧载，安装包继续不纳入 Git。

## 0.5.3 · 2026-08-31

本版正式收录 8 月 30 日下午到傍晚完成的真机性能、长按删除、实况播放和上滑删除调整，并与 Android 对齐为 `0.5.3`（build `53`）。本地未签名构建输出为 `iOS/IPA/Punctum-0.5.3-unsigned.ipa`，安装包不纳入 Git，真机安装前仍需签名。

### 首页中文标题

- 封面中文用 **Noto SemiBold** 的 `UILabel`（`GalleryTitleLabel` / `LockedFontLabel` / `CenteredTitleHost`），英文用 Newsreader SemiBold。不要走 SwiftUI `Button` 默认合成加粗。
- **禁止描边。** 加粗两号时只改字重，不要描边充粗。
- 胶片中文标题在槽内垂直居中，再上移约 `pointSize * 0.1` 做光学对齐；不要再给中文加 `offset(y: 3)`。英文胶片标题仍保留 `offset(y: 3 * visualScale)`。
- 图集选择列表的中文和数字不要被系统加粗；用锁定字重的 Label。

### 大图集列表性能

- 进画廊先取 **80** 张（`galleryPageCount`），滑到底再 `loadMorePhotos`。不要一进来就扫完 Recents 里几万张。
- 缩略图长边 360、`skipDegraded: false`，`PhotoThumbnailCache` 按 id + size 缓存。
- 列表不要对每张图查 `PHAssetResource`。真机滑动已确认明显好转。

### 列表长按删除

- 根因：以前长按要等滑动失败，圈和系统删除框几乎同时出现；SwiftUI 小圈还会被透明 UIView 挡住。
- 现为 `GridPressCatcher` + UIKit `DeleteBadgeView`，圈画在手势层右上角。preview 约 0.22s、commit 约 0.7s，`allowableMovement = 8`。
- 用 `shouldBeRequiredToFailBy` 让滑动优先，不要再 `shouldRequireFailureOf pan`。
- **只有单击进大图。** 长按松手（没删成）不能进大图（`ignoreTap` + 约 0.4s）。

### 大图实况

- 角标贴 **原图图像区域右下角**：26pt 图标 + 6pt 边距，热区 **44×44**，不要再扩成 52+12 再 inset。图标 `allowsHitTesting(false)`，点击由整页 catcher 处理。
- 点角标只 `playOnce`，不切图。屏幕左右 25% 切上一张 / 下一张；中间点开关控件。
- 长按：`requestLivePhoto` 用 `.opportunistic`，第一张非空（含 degraded）就用；`PHLivePhotoView` 关掉系统自带长按；开播前 `AVAudioSession` `.playback`。mode 已是 hold/playOnce 时，livePhoto 后到也要自动 `startPlayback`。
- 不要先震再空播：`startPlayback` 在 `livePhoto == nil` 时只记 mode，资源到了再播。

### 大图上滑删除

- **不要**再对整个 `TabView` 做 scale / offset。缩小过程里还能左右翻，删完就会闪。
- 手势成立时 `window.drawHierarchy` 截一张静图，藏起 TabView，只对这张图做缩小推向删除键（参数仍用原来的 `pageScale` / `pageOffset` / `pageRadius` / `pageRotation`）。
- 背后放下一张的静态 `DetailPage`（`pagingEnabled: false`）。松手不删则丢掉截图、恢复 TabView。
- 删除提交时用 `Transaction.disablesAnimations`，先记下下一张 id 再改 `pendingDeletedIDs`。

### 接手注意

- 大图入口：`Views/DetailScreen.swift`、`Views/LivePhotoViews.swift`；列表手势：`Views/GalleryScreen.swift`；分页：`GalleryViewModel.swift` / `PhotoLibraryService.swift`。
- 模拟器没有真机实况时，会写入 LIVE A / LIVE B 合成 Live Photo。真机用系统拍的实况即可。
- Debug 编进模拟器若遇到资源目录问题，可参考：`CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY="-" AD_HOC_CODE_SIGNING_ALLOWED=YES`，以及必要时 `EXCLUDED_SOURCE_FILE_NAMES=Assets.xcassets`。
